# Stitch Path Fields

Represent stitches as repeated oriented line segments placed along curves or grids. Each segment has length, width, angle, jitter, color, and height.

## Controls

- stitch_length
- stitch_spacing
- thread_width
- height_strength
- jitter_amount
- fabric_noise
- color_palette
- curve_following

## Output Goal

The result should look like thread placed on cloth, not generic stripes or noise.
