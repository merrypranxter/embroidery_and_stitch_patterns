# Grid Chart Generation

Counted embroidery can be generated as a grid of X marks, diagonal strokes, or small thread glyphs. Color palettes map to thread keys.

## Controls

- stitch_length
- stitch_spacing
- thread_width
- height_strength
- jitter_amount
- fabric_noise
- color_palette
- curve_following

## Output Goal

The result should look like thread placed on cloth, not generic stripes or noise.
