# Sashiko Running Stitch Generator

Sashiko-like patterns can be generated by dashed lines on geometric paths, but spacing and repeat logic must remain disciplined.

## Controls

- stitch_length
- stitch_spacing
- thread_width
- height_strength
- jitter_amount
- fabric_noise
- color_palette
- curve_following

## Output Goal

The result should look like thread placed on cloth, not generic stripes or noise.
