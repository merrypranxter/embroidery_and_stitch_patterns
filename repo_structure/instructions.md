# Repository Structure Instructions

This pack is meant to be dropped into `merrypranxter/embroidery_and_stitch_patterns` as a large starter expansion.

The repository should function as:

- a stitch reference archive
- a motif and pattern grammar archive
- a cultural/traditional technique index
- a prompt-generation source
- a shader/generative-art reference
- a production-translation guide for vector, print, and apparel use

When adding new files, ask which layer the topic belongs to:

- Is it a stitch technique? Put it in `01_stitch_families`.
- Is it a motif or layout family? Put it in `02_pattern_families` or `08_composition_and_motif_grammar`.
- Is it counted grid logic? Put it in `03_counted_thread_and_grid`.
- Is it a named cultural or historical tradition? Put it in `05_cultural_and_historical_traditions`.
- Is it shader/code/prompt/output logic? Put it in the relevant technical section.
