# Brazilian Dimensional Embroidery

## Respectful Reference Note

Raised floral embroidery using rayon threads and dimensional stitches like bullion, cast-on, drizzle, and woven forms.

This file is for visual and structural reference. Treat living textile traditions with respect. Do not flatten them into generic `ethnic pattern` sludge. When making prompts or derivative work, name the structural traits you are actually using: stitch type, motif layout, color behavior, ground fabric, and density.

## Visual Traits

- culturally specific motif vocabulary
- repeated stitch rhythm
- fabric-ground relationship
- regional or historical color logic
- handmade density and variation

## Prompt Module

`Brazilian Dimensional Embroidery embroidery reference, respectful textile study, visible stitch structure, cloth ground, motif grammar, thread texture, not printed`

## Drift Warnings

Avoid costume-shop stereotypes, random symbols, and fake authenticity claims. Use the repo as a vocabulary map, not a permission slip to make nonsense sacred-looking textile soup.
