# Stumpwork

Stumpwork is dimensional raised embroidery using padded forms, wired petals, detached elements, beads, and sculptural thread. It is embroidery attempting to leave the fabric plane.

## Visual Traits

- visible raised surface
- strong material behavior
- stitch direction matters
- shadows appear at thread edges
- irregularities make it feel real

## Prompt Module

`stumpwork, tactile embroidery texture, raised thread, cloth ground, material-specific stitching, macro textile detail`
