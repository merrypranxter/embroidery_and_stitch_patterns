# Couching

**Family:** laid thread

## Visual Signature

Couching reads as long thread held down by tiny stitches, good for metallics and thick cords. It is useful when the embroidery needs to communicate thread path rather than printed ink. The stitch has visible direction, spacing, and tension, so it should never look like a generic drawn line pasted onto cloth.

## Construction Logic

Think of this stitch as a repeatable needle-path unit. The surface thread forms a visible mark; the underside carries the thread invisibly between entry and exit points. The look changes when stitch length, spacing, curve tightness, thread weight, and fabric count change.

## Best Uses

Use for goldwork lines, curves, lettering. In AI prompts, pair the stitch with clear scale words: `tiny`, `bold`, `dense`, `open`, `raised`, `loose`, `precise`, or `folk-style`.

## Visual Variables

- stitch length
- spacing or density
- thread thickness
- fabric ground visibility
- curve handling
- tension regularity
- sheen direction
- color contrast

## Prompt Module

`couching embroidery, visible individual stitches, thread entering and exiting fabric, tactile raised thread texture, handmade spacing variation, not printed, not flat ink`

## Drift Warnings

Do not let this become generic vector line art. The stitch needs visible thread width, tiny relief, and evidence of repeated needle movements. If the result looks like a printed illustration, add stronger words: `raised thread`, `stitched surface`, `fiber shadows`, `needle holes`, and `cloth grain`.
