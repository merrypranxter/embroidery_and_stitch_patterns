# Style Mixing Templates

- Embroidery + glitchcore: stitched signal corruption, broken thread paths, neon knots as dead pixels.
- Embroidery + op art: blackwork fills using optical tiling, thread-grid illusion fields.
- Embroidery + dither: cross-stitch and seed-stitch density acting as tactile dithering.
- Embroidery + fungi: mycelium stem-stitch networks, French-knot spores, satin mushroom caps.
- Embroidery + quilting: embroidered outlines and knots over patchwork block geometry.
