# Master Prompt Formula

Use this formula when generating embroidery images:

```text
[SUBJECT/MOTIF] rendered as [EMBROIDERY TRADITION OR STITCH FAMILY] on [GROUND FABRIC], using [THREAD TYPE/COLOR PALETTE], with visible [STITCH TYPES], [DENSITY/TEXTURE NOTES], [RELIEF/SHEEN/GRID DETAILS], photographed or illustrated as [OUTPUT STYLE], not printed, not painted, tactile raised thread
```

## Example

```text
psychedelic moth and moon motif rendered as surface embroidery on black cotton twill, using neon cotton floss and metallic silver couching, visible satin stitch wing panels, chain stitch outlines, French knot stars, seed stitch dust, raised thread ridges, cloth grain visible, handmade spacing variation, macro textile illustration, not printed, not flat ink
```
