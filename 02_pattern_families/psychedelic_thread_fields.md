# Psychedelic Thread Fields

## Pattern Identity

Psychedelic Thread Fields uses radiating loops, color gradients, vibrating motifs. The embroidered version should feel built from thread decisions, not printed motif wallpaper.

## Stitch Strategy

This family chain spirals, variegated thread, dense knot stars. Choose stitch types based on visual role: outlines need line stitches, filled forms need satin or long-and-short logic, gritty texture needs seed or knots, and raised emphasis needs couching, bullion knots, stumpwork, beads, or layered thread.

## Composition Rules

- Give the motif a readable silhouette.
- Let stitch direction follow the form.
- Vary density between focal areas and background.
- Use knots, couching, or metallics as accents, not as random glitter dandruff.
- Keep fabric visible where the design needs breath.

## Prompt Module

`psychedelic thread fields rendered as real embroidery on fabric, visible stitch families, thread texture, slight handmade irregularity, cloth grain visible, raised tactile surface, not a flat printed pattern`

## Production Translation

For screenprint or vector use, translate thread into line families, contour strokes, dot knots, rope borders, satin-fill bands, and dashed running-stitch paths. Preserve stitch rhythm even if actual thread relief cannot be printed.
