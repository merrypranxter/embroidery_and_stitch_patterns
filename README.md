# Embroidery And Stitch Patterns

Thread goblin headquarters: a repository for hand embroidery, counted-thread systems, decorative stitches, historic surface techniques, machine embroidery logic, stitch-chart grammar, AI prompt modules, shader/code translations, and production-friendly pattern thinking.

This repo treats embroidery as **line, dot, loop, knot, fill, couch, grid, relief, texture, and rhythm**. A stitch is not just decoration. A stitch is a small physical algorithm: needle path + thread tension + cloth ground + repetition + light.

## What this repo is for

- AI image prompting and style analysis
- textile pattern generation
- embroidery reference and design planning
- screenprint/vector translation
- shader and generative-art experiments
- stitch-chart and motif grammar
- culturally aware pattern vocabulary
- drift control so models do not turn all embroidery into generic floral Etsy soup

## Core idea

Embroidery turns a surface into a terrain of thread gestures.

At the smallest scale, embroidery asks:

- where does the needle enter?
- where does the needle exit?
- how long is the exposed thread?
- is the thread flat, raised, twisted, looped, knotted, couched, cut, or packed?
- does the stitch follow a drawn line, a counted grid, a woven structure, or a freehand gesture?
- does the motif read through outline, fill, negative space, relief, shimmer, or repetition?

## Design rule

Good embroidery is not just a picture with thread texture slapped on it. The **stitch choice must explain the form**.

Outline stitches describe edges. Satin fills make smooth petals and letters. Knots become pollen, stars, eyes, grit, berries, bead-like raised details. Couching makes metallic lines behave. Counted stitches turn the cloth into a pixel grid. Whitework turns absence, holes, and pulled thread into architecture.

The needle is the plotter. The thread is the ink. The fabric is the grid. The goblin is loose.
