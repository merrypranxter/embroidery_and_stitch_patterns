# Shader Prompt Examples

```text
Create a GLSL-style stitch field shader: curves are rendered as repeated thread capsules with anisotropic highlights, French knots as raised circular bumps, fabric grain as subtle noise, and stitch jitter controlled by a uniform. The output should feel like embroidery on cloth, not neon lines.
```

```text
Make a p5.js counted cross-stitch generator. Use a grid of X-shaped stitches, selectable palette, random motif symmetry, backstitch outlines, and fabric-hole background texture. Include save PNG and reseed controls.
```
