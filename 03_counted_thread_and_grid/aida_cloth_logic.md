# Aida Cloth Logic

Aida cloth is a gridded fabric ground where each stitch cell is easy to count. It is ideal for cross stitch and other counted-thread work because the fabric itself provides the pixel grid.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
