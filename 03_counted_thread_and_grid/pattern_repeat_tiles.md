# Pattern Repeat Tiles

Counted motifs can tile seamlessly when chart edges match. Repeat units should consider cell size, color transitions, and border continuity.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
