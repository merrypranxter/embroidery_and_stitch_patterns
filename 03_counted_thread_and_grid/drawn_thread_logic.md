# Drawn Thread Logic

Drawn-thread work removes or gathers fabric threads to create openwork. The pattern emerges from manipulating the ground itself.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
