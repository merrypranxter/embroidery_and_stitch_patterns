# Chart Symbols And Color Keys

Counted embroidery charts convert motifs into grid cells, each marked by symbols corresponding to thread colors. This is a pixel-art-like design language but with thread thickness and fabric count constraints.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
