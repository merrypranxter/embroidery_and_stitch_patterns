# Cross Stitch Pixel Logic

Cross stitch turns each grid cell into an X. Visual density comes from cell count, color placement, partial stitches, and backstitched outlines.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
