# Grid To Svg Translation

A counted-thread grid can be exported as SVG squares, X marks, diagonal strokes, or stitch glyphs. This is useful for pattern previews and generative textile diagrams.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
