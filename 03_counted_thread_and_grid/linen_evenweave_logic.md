# Linen Evenweave Logic

Evenweave linen supports counted work with finer, more elegant spacing than Aida. Stitches may be worked over one or two threads, changing scale and detail density.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
