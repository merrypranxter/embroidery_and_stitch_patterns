# Blackwork Fill Logic

Blackwork uses repeated geometric line fills on a counted grid. Tone is created by pattern density rather than color blending.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
