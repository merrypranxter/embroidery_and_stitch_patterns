# Redwork Line Logic

Redwork traditionally uses outline stitching in one color, often red, to make simple narrative or decorative line drawings.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
