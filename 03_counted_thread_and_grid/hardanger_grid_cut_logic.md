# Hardanger Grid Cut Logic

Hardanger combines satin blocks, counted grids, cut threads, and woven bars. It is embroidery as architectural negative space.

## Key Variables

- fabric count
- grid cell size
- stitch direction
- color symbol
- backstitch overlay
- border repeat
- negative space

## AI Prompt Hook

`counted-thread grid, visible fabric holes, chart-like precision, thread crosses occupying cells, pixel-like but tactile`
